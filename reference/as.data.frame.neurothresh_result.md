# Coerce a neurothresh result's clusters to a data frame

Coerce a neurothresh result's clusters to a data frame

## Usage

``` r
# S3 method for class 'neurothresh_result'
as.data.frame(x, row.names = NULL, optional = FALSE, ...)
```

## Arguments

- x:

  A `neurothresh_result`.

- row.names:

  Ignored.

- optional:

  Ignored.

- ...:

  Unused.

## Value

Data frame of clusters, or an empty data frame if none.
