# Summarize a neurothresh result

Summarize a neurothresh result

## Usage

``` r
# S3 method for class 'neurothresh_result'
summary(object, ...)
```

## Arguments

- object:

  A `neurothresh_result`.

- ...:

  Unused.

## Value

The result object invisibly; prints a richer summary including cluster
table head when present.
